## Local development

```bash
npm install
npm run dev -- --port 43123 --host 127.0.0.1
```

Open [http://127.0.0.1:43123](http://127.0.0.1:43123).

## Deploy

- **Build command:** `npm run build`
- **Deploy command:** `npx wrangler deploy`
